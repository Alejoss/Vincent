# Suscriptores newsletter

Lista maestra de suscriptores. Edita esta tabla en Obsidian; la app de envío la lee al mandar campañas.

**Columnas:** `email`, `nombre`, `segmento`, `activo`, `notas`

- **email** — correo del suscriptor (obligatorio)
- **nombre** — para personalizar el saludo
- **segmento** — grupo de envío (`test`, `general`, `club-de-lectura`, …)
- **activo** — `sí` o `no`
- **notas** — opcional

**Segmento `test`:** solo correos tuyos para pruebas antes de enviar a `general`.

**Segmento `club-de-lectura`:** solo quien se inscribió al seminario (landing). No incluir aquí a toda la lista `general`.
